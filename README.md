


# py-music-dl

一款纯 Python 编写的命令行音乐下载工具，支持从多个主流音乐平台搜索和下载歌曲。

> **声明**：本项目仅供学习爬虫技术、`requests` 和 `BeautifulSoup` 使用，请遵守各平台协议及版权规定，勿用于商业用途。

## 功能特性

- **多平台聚合搜索**：同时从咪咕音乐、网易云音乐、QQ 音乐、酷我音乐四个平台搜索，结果交错公平展示
- **一键下载**：输入关键词即可搜索并下载歌曲，支持 MP3 / FLAC / WAV 等格式
- **自动音质识别**：根据下载链接自动识别 320K 高品质与 LOSSLESS 无损音质
- **BeautifulSoup 教学演示**：内置 BS4 核心 API 速览及实战抓取演示，适合学习爬虫入门
- **进度显示**：下载过程中实时显示进度条及文件大小
- **交互式操作**：简洁的终端交互，按序号选择歌曲，即时反馈

## 环境要求

- Python **3.8+**（推荐 3.10+）

## 安装

```bash
pip install requests beautifulsoup4 lxml urllib3
```

或：

```bash
pip install -r requirements.txt
```

## 快速开始

```bash
python3 music.py
```

运行后按提示操作：

1. 输入要搜索的歌曲名称
2. 从多平台交错排列的结果中选择歌曲序号
3. 自动获取详情并下载，文件保存在 `downloaded_music/` 目录

## 支持平台

| 平台              |  搜索   |  下载   | 音质              |
|-----------------|:-----:|:-----:|-----------------|
| 咪咕音乐 (Migu)     |   ✅   |   ✅   | 320K / LOSSLESS |
| 网易云音乐 (NetEase) |   ✅   |   ✅   | 320K / LOSSLESS |
| QQ 音乐 (QQ)      |   ✅   |   ✅   | 320K / LOSSLESS |
| 酷我音乐 (Kuwo)     |   ✅   |   ✅   | 320K / LOSSLESS |

## 项目结构

```
py-music-dl/
├── music.py              # 主程序（单文件，包含全部逻辑）
│   ├── MusicAPI          #   各平台搜索与详情 API 封装
│   │   ├── search_migu()      #   咪咕音乐搜索
│   │   ├── search_netease()   #   网易云音乐搜索
│   │   ├── search_qq()        #   QQ 音乐搜索
│   │   ├── search_kuwo()      #   酷我音乐搜索
│   │   ├── get_migu_detail()      #   咪咕详情
│   │   ├── get_netease_detail()   #   网易云详情
│   │   ├── get_qq_detail()        #   QQ 音乐详情
│   │   └── get_kuwo_detail()      #   酷我详情
│   ├── MusicDownloader   #   下载管理器（搜索、展示、选择、下载流程）
│   └── BS4Demo           #   BeautifulSoup 教学演示模块
└── downloaded_music/     # 下载文件保存目录
```

## 注意事项

- 请确保网络连接正常，部分 API 可能需要稳定的网络环境
- 各平台 API 为第三方聚合接口，偶有波动，如遇失败可稍后重试
- 下载歌曲仅供个人学习用途，请尊重版权
- 部分歌曲可能因版权原因无法获取下载链接
