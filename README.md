

# py-music-dl

一款纯 Python 编写的命令行音乐下载工具，支持从多个主流音乐平台搜索和下载歌曲。

## 功能特性

- **多平台搜索**: 支持网易云音乐、QQ 音乐、酷我音乐、咪咕音乐等平台
- **一键下载**: 输入关键词即可搜索并下载歌曲
- **多种音质**: 提供不同音质的下载选项
- **命令行交互**: 简单的终端交互界面
- **进度显示**: 下载过程中实时显示进度条

## 依赖环境

- Python 3.6+
- 请求库 (`requests`)
- Beautiful Soup 4 (`bs4`)

## 安装说明

```bash
pip install requests bs4
```

## 使用方法

运行程序:

```bash
python music.py
```

1. 输入你要搜索的歌曲名称
2. 从搜索结果中选择歌曲序号
3. 选择下载音质
4. 等待下载完成

## 项目结构

```
music.py          # 主程序文件
├── MusicAPI      # 各平台 API 接口封装
│   ├── search_migu      # 咪咕音乐搜索
│   ├── search_netease    # 网易云音乐搜索
│   ├── search_qq        # QQ音乐搜索
│   └── search_kuwo      # 酷我音乐搜索
├── MusicDownloader     # 下载器类
│   ├── search_all       # 全平台搜索
│   ├── get_detail      # 获取歌曲详情
│   └── download_mp3    # 下载MP3文件
└── BS4Demo       # 工具演示类
```
